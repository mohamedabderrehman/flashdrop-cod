# النشر وحل المشكلات

## التاريخ

صفحة بيع جزائرية مركزة مع إجراءات طلب. المخزون والتقييمات والعروض في العرض بيانات تقديمية.

## البيئة المحلية

يلزم PHP 8.1 أو أحدث وcURL لنداءات Telegram الحية. وضع العرض الافتراضي 1 لا يحتاج مفتاحاً. للوضع الحي صدّر DEMO_MODE=0 وTELEGRAM_BOT_TOKEN وTELEGRAM_CHAT_ID في الخادم واجعل ORDER_STATE_DIR خارج المجلد العام قابلاً لكتابة الخدمة فقط. استخدم خيارات api/options.json ومفتاح منع تكرار جديداً لكل طلب مختلف.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

يُفحص طول البلدية دون قائمة إدارية شاملة. يحتاج الإرسال الحي غير المؤكد مراجعة المشغل ولا يُعاد بمفتاح جديد عشوائياً. العروض والمخزون والمراجعات محتوى تقديمي.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
