# عرض اصطناعي

اختيار النوع والتوصيل ← فحص الحقول ← إرسال PHP مع مفتاح منع التكرار ← تحقق الخادم ← قبول العرض أو تأكيد Telegram ← عرض رقم الطلب من الخادم.

## الوظائف المراد عرضها

- صور منتج وتخطيط بيع متجاوب
- فحص هاتف جزائري وحقول الولاية والبلدية
- توصيل منزلي أو مكتب ولون ومقاس وإجمالي الكمية
- استعادة النموذج وحالات التحميل والمحاولة
- إرسال Telegram من الخادم ووضع عرض دون مزود

## خطوات التنفيذ التفصيلية

1. Submit synthetic Algerian phone/name and a valid variant.
2. Change quantity and delivery option; inspect totals.
3. Submit invalid fields directly to PHP; expect rejection.
4. Repeat the same idempotency key; verify the same receipt. Use a changed payload with that key; expect conflict.

## توثيق الدليل

التقط الصور من التطبيق الفعلي بحسابات اصطناعية وسجل المكون وحجم الشاشة والإعداد. نص خطوات العرض ليس فيديو مسجلاً. قِس الأداء مع حجم المدخلات والجهاز والوقت وحالة التخزين المؤقت.

تُفحص أسماء البلديات من حيث الطول وليس من قائمة إدارية شاملة. لا توجد معالجة دفع. تحتاج نتائج إرسال Telegram غير المؤكدة إلى مراجعة المشغل.
